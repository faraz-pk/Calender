# 📅 Calender

A simple and responsive Calendar application built using HTML, CSS, and JavaScript.
This app displays dates, days, months, and year information in a clean and interactive interface.

---

## 📌 Features

* Display current date and time
* Interactive calendar layout
* Responsive design
* Simple and clean user interface
* Lightweight and fast application

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
